# MirvDesk 1.7 — обновления из собственных релизов

Источник обновлений: **только**
`https://github.com/mirivlad/mirvdesk-client/releases`.
Код не обращается к `api.rustdesk.com` для MirvDesk и не
использует upstream-дистрибутивы RustDesk.

## Debian/Ubuntu (.deb)

При установке пакета `mirvdesk` регистрируются
`mirvdesk-update.service` и `mirvdesk-update.timer`:
- первый запуск после загрузки, затем примерно раз в сутки;
- API GitHub Releases, строгая проверка названия файла, версии,
  канала (stable/preview), размер и SHA-256 (GitHub asset digest);
- перед скачиванием и перед установкой запрашивается
  `mirvdesk --update-idle`, проверяющий процессы `--server`
  через IPC; при активных или неизвестных подключениях установка
  откладывается;
- проверенный `.deb` устанавливается через `dpkg -i`;
- обновления из preview доступны только если уже установлена
  предварительная версия MirvDesk;
- для установленного варианта `mirvdesk-unattended-wayland`
  потребуется отдельный канал/сопоставление пакетов — пока не
  поддерживается; другие менеджеры пакетов тоже не поддерживаются.

Проверить состояние:

```sh
systemctl status mirvdesk-update.timer
journalctl -u mirvdesk-update.service -n 80
```

Запустить проверку вручную (обычно не требуется):

```sh
sudo systemctl start mirvdesk-update.service
```

Отключить автоматические установки:

```sh
sudo systemctl disable --now mirvdesk-update.timer
```

## Windows

Установленный MirvDesk проверяет собственные релизы (preview
обновляется внутри preview), скачивает подходящий `msi` или
`exe`, сверяет размер и SHA-256 из GitHub и запускает
существующий установщик обновлений RustDesk **только после**
проверки отсутствия активных подключений. Диспетчер установки
Windows может запрашивать подтверждение в зависимости от
режима установки и прав пользователя.

## macOS / Android / Flatpak / RPM

Автоматическая установка **пока не реализована**; не следует
ожидать беззвучной установки на Android (она регулируется ОС).
Доступны установочные файлы на GitHub Releases.

## Переход с 1.6

В 1.6.2 проверка обновлений форка была отключена, поэтому
один раз установить 1.7 preview придётся вручную.
Дальнейшие обновления Debian/Windows 1.7 уже будут
искаться в релизах форка. Обновление сохраняет настройки
MirvDesk, но тестовые релизы могут содержать незавершённые
функции Linux multi-session.

Первая ветка тестирования — `v1.7.0-1`, без претензии
на готовность маршрутизации параллельных Linux сеансов.
