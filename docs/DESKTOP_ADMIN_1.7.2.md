# MirvDesk 1.7.2 — администрирование из клиента

Панель администратора теперь включена непосредственно в настольный клиент
(Windows, Linux, macOS). Отдельный веб-интерфейс не требуется.

## Где искать

**Настройки → Аккаунт → Управление пользователями и устройствами**

Кнопка видна только после успешного входа в аккаунт MirvDesk с ролью
администратора. Вход в Windows/Linux с привилегиями ОС не заменяет
авторизацию на MirvDesk Server.

Открывается отдельная вкладка **Administration**:

- **Users**: просмотр, создание обычных учётных записей, блокировка и
  разблокировка, смена пароля.
- **Groups**: создание, переименование, удаление групп и изменение состава.
- **Devices**: принадлежность к группам (в том числе нескольким),
  примечания, последнее подключение к аккаунту.
- **Audit**: журнал действий администратора.

## Сервер

Нужен MirvDesk Server **1.7.1+**, содержащий `/api/admin/*`.
Сервер проверяет права роли независимо от видимости кнопки в клиенте.
Обычный пользователь не может выполнять административные запросы.

Ошибки `401/403` означают отсутствие действительного входа или прав;
`404` — отсутствие API на сервере. Проверьте версию контейнера,
а не только клиента. Не путайте API-сервер и rendezvous `hbbs`.

## Примечание

Панель перенесена из экспериментальной ветки `feature/desktop-admin-page-1.7`
в клиент 1.7.2. При этом код терминальной многосеансовости Linux остаётся
незавершённым.
